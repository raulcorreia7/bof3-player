# Security policy

Report a vulnerability privately: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/raulcorreia7/bof3-player/security/advisories/new).
Do not open a public issue for it. Include the affected file or command and the steps to reproduce.
Do not attach game data.

## Scope

The disc, EMI, sound-bank and audio decoders read untrusted files. Crashes, out-of-bounds access, unbounded memory use and writes outside the output path are in scope.

## Supported versions

The latest release and `main`.
