# Security policy

Report a vulnerability privately. Open the repository's
[Security tab](https://github.com/raulcorreia7/bof3player/security) and choose "Report a vulnerability".
Do not open a public issue for a vulnerability.

## Scope

The disc, EMI, sound-bank and audio decoders read untrusted files. Crashes, out-of-bounds access, unbounded memory use and writes outside the output path are in scope. Report the file or command that triggers the problem; do not attach game data.

## Supported versions

The latest release and `main`.
