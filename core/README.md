# bof3player

The Rust library behind the player. It has the catalog, sources, playback and WAV, FLAC and Ogg export: `Library`, `Source`, `Player` and `Naming`.

```sh
# from the repository root
cargo test -p bof3player --all-features
```

The command and the window are the `bof3player-app` crate in `app/`. Guides: [Rust API](../docs/rust-api.md), [the command](../docs/player.md).
